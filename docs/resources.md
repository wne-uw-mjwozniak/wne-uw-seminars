# Resources

## Faculty and university

- [WNE UW: diploma theses](https://www.wne.uw.edu.pl/student/prace-dyplomowe)
- [APD: thesis archive](https://apd.uw.edu.pl/)
- [Course syllabus in USOS](https://usosweb.uw.edu.pl/kontroler.php?_action=katalog2/przedmioty/pokazPrzedmiot&kod=2400-PL3SL339A)

## LaTeX

- [Overleaf documentation](https://www.overleaf.com/learn): start with "Learn LaTeX in 30 minutes"
- [TeX Live](https://www.tug.org/texlive/) and [MacTeX](https://www.tug.org/mactex/): local installations
- [`elsarticle` on CTAN](https://ctan.org/pkg/elsarticle): the class used by the article template
- [International Journal of Forecasting](https://www.sciencedirect.com/journal/international-journal-of-forecasting): guide for authors

## git and GitHub

- [Pro Git](https://git-scm.com/book): free book; chapters 1 to 3 are enough to start
- [GitHub Projects documentation](https://docs.github.com/en/issues/planning-and-tracking-with-projects)
- [GitHub Student Developer Pack](https://education.github.com/pack)

## Reproducible environments

- [`uv` documentation](https://docs.astral.sh/uv/): Python projects with `pyproject.toml` and a lock file
- [`renv` documentation](https://rstudio.github.io/renv/): the same idea for R

## Forecasting and machine learning

- Hyndman and Athanasopoulos, [*Forecasting: Principles and Practice*](https://otexts.com/fpp3/) (free online)
- [Chronos on GitHub](https://github.com/amazon-science/chronos-forecasting)
- [TabPFN on GitHub](https://github.com/PriorLabs/TabPFN)
